2. Offline device activation

The installed application exports an activation-request.json containing a one-way code derived from the OS/platform identity. After payment verification, send this request with your order reference through the private contact on your receipt. The seller delivers a signed licence bound to that device. Import the licence to unlock Learn and Work. No DataLeek account, automatic device upload or activation server is required.

Copying the installer, application folder or licence to a computer with a different device code does not activate that computer. New installations require activation; there is no unrestricted executable trial. Unactivated installations can preview learning content and view/export existing local work. Device binding deters ordinary licence sharing and is not a promise of tamper-proof DRM.

An application reinstall that preserves the same OS/platform identity can reuse the signed licence. Contact the seller with your receipt and a new activation request for a reviewed manual transfer. Stop using the previous installation when transferring the licence. Offline licensing cannot remotely deactivate an old installation, detect every cloned OS identity, or guarantee recovery without proof of purchase. Transfers do not create a second concurrent entitlement.
